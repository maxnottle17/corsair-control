How the app works with the keyboard

Lighting

While you hold Fn, every light goes off except the keys that have an Fn shortcut and any buttons you have given a job. This only happens when the app takes full control.

Dial

Pick what the dial does. Turning and pressing it both follow the mode.

Choosing a mode saves it into the keyboard (the lights pause for a second). Fn + F12 still steps through the keyboard's other built-in modes.

Buttons

Game mode is switched off while this app is running. The Game Mode button does nothing unless you give it a job here.

Jobs are saved into the keyboard. Media controls and shortcuts then work even when this app is closed; the other jobs need the app running.

Side screen

Pictures are saved in the keyboard itself. Click one to show it; the first slot is the keyboard's own built-in display.

Pictures are cropped to fill the 248 × 170 picture area. Animated GIFs are not supported yet.

Response rate

The keyboard disconnects for a few seconds when this changes.
